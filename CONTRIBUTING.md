# Contributing

1. Create a focused branch from the default branch.
2. Keep commits small and use imperative commit subjects.
3. Run `./mvnw.cmd test` and `npm run build` in `frontend/`.
4. Update API or setup documentation when behavior changes.
5. Open a pull request that explains the change and how it was verified.

Do not commit secrets, generated build output, IDE metadata, or local database
files.
